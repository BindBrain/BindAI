# First Agent

In BindAI, an **Agent** is the core building block of every AI application.

An agent combines:

* A language model
* Instructions
* Tools
* Memory
* Knowledge retrieval
* Middleware
* Event hooks

into a single reusable component.

Unlike calling an LLM directly, a BindAI agent can reason, call tools, remember conversations, retrieve documents, and participate inside workflows.

---

# Creating an Agent

The simplest agent only requires a provider and a model.

```python
from bindai import Agent

agent = Agent(
    provider="openai",
    model="gpt-4.1-mini",
    instructions="You are a helpful assistant.",
)
```

Run the agent.

```python
result = agent.run("Explain what BindAI is.")

print(result.output)
```

Output:

```text
BindAI is an open-source Python framework for building AI agents, workflows, memory, tools, and production-ready AI applications.
```

---

# Agent Parameters

The constructor accepts several optional parameters.

```python
Agent(
    name="assistant",
    provider="openai",
    model="gpt-4.1-mini",
    instructions="You are a helpful assistant.",
)
```

| Parameter      | Description                                          |
| -------------- | ---------------------------------------------------- |
| `name`         | Agent name used for logging and workflows            |
| `provider`     | LLM provider (`openai`, `anthropic`, `ollama`, etc.) |
| `model`        | Model name                                           |
| `instructions` | System prompt for the agent                          |

---

# Using the Builder API

BindAI also includes a fluent builder.

```python
from bindai import AgentBuilder

agent = (
    AgentBuilder()
    .name("assistant")
    .model("openai:gpt-4.1-mini")
    .instructions("You are a helpful assistant.")
    .build()
)
```

The builder makes it easy to configure agents incrementally.

---

# Sending Prompts

The primary execution method is:

```python
result = agent.run("Explain dependency injection.")
```

The returned value is an `AgentResult`.

```python
print(result.success)

print(result.output)

print(result.error)
```

Example:

```text
True

Dependency injection is a software design pattern where dependencies are supplied from the outside rather than created internally.
```

# Conversations

Agents automatically understand conversation history when a memory provider is attached.

Without memory:

```python
agent.run("My name is Alice.")

agent.run("What's my name?")
```

The model may not remember.

With memory:

```python
from bindai import InMemoryMemory

agent.use_memory(InMemoryMemory())

agent.run("My name is Alice.")

agent.run("What's my name?")
```

The agent now retrieves previous conversation history before sending prompts to the model.

# System Instructions

Instructions define the behavior of an agent.

```python
agent = Agent(
    provider="openai",
    model="gpt-4.1-mini",
    instructions="""
You are a senior Python engineer.

Always explain concepts clearly.

Use concise answers.

Prefer practical examples.
""",
)
```

Good instructions describe:

* Role
* Tone
* Constraints
* Formatting rules
* Desired behavior

# Structured Output

Agents can return structured objects instead of plain text.

```python
from pydantic import BaseModel


class Person(BaseModel):
    name: str

    age: int
```

Generate structured data.

```python
result = agent.run(
    "Generate a fictional person.",
    output=Person,
)

print(result.output)
```

Result:

```python
Person(
    name="Alice",
    age=28,
)
```

BindAI automatically asks the model to generate output matching the schema.

# Streaming Responses

For chat interfaces, stream tokens as they are generated.

```python
for chunk in agent.stream("Explain neural networks."):
    print(chunk.delta, end="")
```

Streaming is recommended for:

* Chat applications
* Long responses
* Real-time interfaces

# Adding Tools

Agents become significantly more capable when tools are attached.

```python
from bindai import tool


@tool
def weather(city: str):

    return f"It is sunny in {city}."
```

Register the tool.

```python
agent.tool(weather)
```

Now the model can invoke the function whenever appropriate.

# Adding Knowledge

Knowledge enables Retrieval-Augmented Generation (RAG).

```python
knowledge = ...

agent.use_knowledge(

```

The agent automatically retrieves relevant documents before generating its response.


Typical use cases:

* Logging
* Authentication
* Metrics
* Prompt inspection

# Loading an Agent from a Project

The easiest way to configure an agent is through a BindAI project.

Project structure:

```text
my_project/

├── bindai.toml
├── agents/
├── tools/
├── workflows/
├── knowledge/
└── main.py
```

Load the project configuration automatically.

```python
from bindai import AgentBuilder

agent = AgentBuilder().from_project().build()
```

The builder loads:

* Provider
* Model
* Temperature
* Registered tools

directly from the project.

---

# Agent Lifecycle

Every execution follows the same pipeline.

1. Receive user input
2. Build the prompt
3. Load memory
4. Retrieve knowledge (optional)
5. Send request to the model
6. Execute tools (if needed)
7. Continue reasoning
8. Produce the final answer
9. Save memory
10. Return an `AgentResult`

This lifecycle remains consistent regardless of the provider being used.

---

# Multi-Provider Support

Switching providers requires only changing the model string.

OpenAI

```python
AgentBuilder().model("openai:gpt-4.1-mini")
```

Anthropic

```python
AgentBuilder().model("anthropic:claude-sonnet-4")
```

Ollama

```python
AgentBuilder().model("ollama:llama3")
```

LM Studio

```python
AgentBuilder().model("lmstudio:qwen3")
```

No application code changes are required.
