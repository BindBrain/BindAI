# Quick Start

This guide gets you from **zero to a working AI application** in just a few minutes.

By the end, you will:

- Create a new BindAI project
- Configure your API key
- Run your first AI agent
- Understand the project structure
- Learn where to continue next

---

# Prerequisites

Before starting, complete the Installation guide.

You should have:

- Python 3.11+
- BindAI installed
- A virtual environment activated
- An OpenAI API key (or another supported provider)

---

# Create a New Project

The fastest way to start is with the BindAI CLI.

```bash
bindai new my-ai-app
```

Enter the project.

```bash
cd my-ai-app
```

Your project will look similar to:

```text
my-ai-app/

├── agents/
│   └── assistant.py
│
├── tools/
│   └── echo.py
│
├── workflows/
│
├── knowledge/
│
├── memory/
│
├── templates/
│
├── tests/
│
├── main.py
├── bindai.toml
├── README.md
└── .env.example
```

---

# Configure Environment Variables

Rename the example environment file.

```bash
cp .env.example .env
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Open `.env` and add your provider credentials.

For OpenAI:

```text
OPENAI_API_KEY=your_api_key_here
```

# Run the Project

Start the application.

```bash
bindai run
```

You should see:

```text

```

Start chatting.

```text
You: Hello
```

Example:

```text
Assistant: Hello! How can I help you today?
```

Congratulations — your first BindAI application is running.

# Understanding What Happened

The scaffold generated several files for you.

## `main.py`

The entry point of the application.

```python
from agents.assistant import agent

agent.run_console()
```

This launches an interactive chat session.

---

## `agents/assistant.py`

Defines your AI agent.

```python
from bindai import Agent

agent = (
    Agent.builder()
    .name("assistant")
    .model("openai:gpt-4.1")
    .instructions(
        "You are a helpful AI assistant."
    )
    .build()
)
```

This creates:

- the AI model
- the instructions
- the execution pipeline

---

## `bindai.toml`

Project configuration.

Example:

```toml
provider = "openai"
model = "gpt-4.1"
temperature = 0.7
```

Changing this file changes the default model for the project.

# Creating an Agent Manually

Instead of using the CLI scaffold, you can create an agent directly.

```python
from bindai import Agent

agent = (
    Agent.builder()
    .model("openai:gpt-4.1")
    .instructions(
        "You are a helpful assistant."
    )
    .build()
)
```

Run it.

```python
result = agent.run(
    "Explain what BindAI is."
)

print(result.output)
```

# Changing Models

Switching providers only requires changing the model string.

OpenAI

```python
.model("openai:gpt-4.1")
```

Anthropic

```python
.model("anthropic:claude-sonnet-4")
```

Ollama

```python
.model("ollama:llama3")
```

LM Studio

```python
.model("lmstudio:qwen3")
```

No other code changes are required.

# Adding Tools

Agents become more useful when they can execute Python functions.

Example:

```python
from bindai import tool

@tool
def add(a: int, b: int):
    return a + b
```

Register it.

```python
agent = (
    Agent.builder()
    .model("openai:gpt-4.1")
    .tool(add)
    .build()
)
```

The model can now call the function automatically when appropriate.

Every generated project follows the same layout.

```text

```

Contains AI agents.

```text

```

Contains reusable tools.

```text

```


Project tests.
