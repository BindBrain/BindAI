# Introduction

Welcome to **BindAI**.

BindAI is an open-source Python framework for building production-ready AI applications with **agents, workflows, tools, memory, knowledge retrieval (RAG), and provider-agnostic language models**.

Instead of writing AI applications from scratch every time, BindAI provides a clean architecture that lets you compose intelligent systems from reusable building blocks. Whether you're building a simple assistant, an enterprise workflow, or a multi-agent platform, BindAI provides the foundation to scale your application without rewriting core components.

---

# Why BindAI?

Modern AI applications quickly become more than a single LLM call.

A production-ready AI system often needs:

* AI agents
* External tools
* Conversation memory
* Knowledge retrieval (RAG)
* Workflow orchestration
* Human approval
* Scheduling
* Multiple language model providers

Without a clear architecture, these features become tightly coupled and difficult to maintain.

BindAI separates every responsibility into independent modules so each part of your application can evolve without affecting the rest of the system.

---

# Core Principles

## Modular

Every BindAI package is designed to work independently.

You can use only the Agent framework, only the Workflow engine, or combine every package into a complete AI platform.

---

## Provider Agnostic

BindAI is not tied to a single AI provider.

The same application can switch between providers such as OpenAI, Anthropic, Ollama, Azure OpenAI, or custom implementations by simply changing the project configuration.

Your application logic remains unchanged.

---

## Production Ready

BindAI was designed for real-world AI applications.

Built-in capabilities include:

* Tool calling
* Structured outputs
* Middleware
* Conversation memory
* Knowledge retrieval (RAG)
* Workflow orchestration
* Human approval
* Scheduling
* Retry policies
* Timeout handling
* Event system

---

## Python First

BindAI embraces modern Python development.

Applications are built using familiar Python classes, functions, decorators, and type hints.

There is no custom scripting language or proprietary workflow syntax to learn.

# Main Components

BindAI is composed of independent packages that work together.

## Projects

Projects organize complete AI applications.

A typical project contains:

* Agents
* Workflows
* Tools
* Knowledge
* Memory
* Configuration
* Templates

Projects generated with the BindAI CLI follow a consistent structure that scales from small assistants to enterprise AI systems.

---

## Agents

Agents communicate with language models and orchestrate AI execution.

Agents can:

* Maintain conversations
* Call tools
* Access memory
* Retrieve knowledge
* Produce structured outputs
* Stream responses

---

## Providers

Providers connect BindAI to different language model services.

The provider layer is completely interchangeable, allowing the same application to work with different LLM vendors.

Supported providers include:

* OpenAI
* Anthropic
* Ollama
* Azure OpenAI
* Custom providers

---

## Tools

Tools allow agents to interact with external systems.

Examples include:

* Python functions
* REST APIs
* Databases
* Search engines
* Internal business services

---

## Memory

Memory enables agents to remember previous interactions.

Memory providers can be swapped independently from agents or workflows.

---

## Knowledge (RAG)

Knowledge provides Retrieval-Augmented Generation (RAG) capabilities.

Documents can be indexed, embedded, searched, and supplied to agents as contextual information during execution.

---

## Workflows

The workflow engine orchestrates complex execution logic.

Supported workflow patterns include:

* Sequential execution
* Conditional branching
* Loops
* Parallel execution
* Retry policies
* Scheduling
* Human approval
* Timeout handling

---

# Command Line Interface

BindAI includes a built-in CLI for creating and running AI projects.

Common commands include:

```bash
bindai new
bindai run
bindai doctor
bindai workflow
bindai inspect
```

The CLI generates production-ready project structures, validates your environment, and runs your applications with minimal configuration.

 │

 ├───────────────┐
 ▼               ▼
Tools        Memory
 │               │
 └──────┬────────┘
        ▼
 Knowledge (RAG)
        │
        ▼
 Provider Resolver
        │
        ▼
 Language Model Provider
        │
 ┌───────────────┬───────────────┬───────────────┐
 │               │               │

Each layer has a single responsibility, making applications easier to test, extend, and maintain.
