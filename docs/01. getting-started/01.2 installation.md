# Installation

This guide walks you through installing BindAI and preparing your development environment.

---

# Requirements

Before installing BindAI, make sure you have:

* Python **3.11 or newer**
* pip
* Git (recommended)

Verify your Python version:

```bash id="pyver01"
python --version
```

---

# Install BindAI

The easiest way to get started is by installing BindAI from PyPI.

```bash id="pipbindai"
pip install bindai
```

Once installed, verify that the CLI is available.

```bash id="clihelp01"
bindai --help
```

If the installation was successful, you'll see the available BindAI commands.

---

# Verify the Python Package

You can also verify the installation from Python.

Start a Python shell:

```bash id="python01"
python
```

Import BindAI:

```python id="import01"
import bindai
```

If no errors occur, the installation was successful.

Exit Python:

```python id="exit01"
exit()
```

---

# Create Your First Project

Generate a new BindAI project.

```bash id="newproj01"
bindai new my-agent
```

Move into the project.

```bash id="cdproj01"
cd my-agent
```

The generated project includes a production-ready structure similar to:

```text id="projecttree01"
my-agent/

├── agents/
├── knowledge/
├── memory/
├── tools/
├── workflows/
├── tests/
├── .env
├── bindai.toml
├── main.py
└── README.md
```

---

# Configure Environment Variables

Most AI providers require an API key.

Open the generated `.env` file and configure your credentials.

Example:

```text id="env01"
OPENAI_API_KEY=your_api_key_here
```

BindAI automatically loads environment variables for supported providers.

---

# Verify Your Environment

Run the built-in diagnostics.

```bash id="doctor01"
bindai doctor
```

The doctor command verifies:

* Python version
* BindAI installation
* Project configuration
* Environment variables
* Provider discovery

Any detected issues include recommendations for fixing them.

---

# Run Your Project

Start the generated application.

```bash id="run01"
bindai run
```

If everything is configured correctly, you'll see something similar to:

```text id="runoutput01"
BindAI Project

You:
```

You can now begin interacting with your AI application.

---

# Development Installation

If you're contributing to BindAI or working directly with the source code, clone the repository and install it in editable mode.

Clone the repository:

```bash id="clone01"
git clone https://github.com/BindBrain/BindAI.git
```

Move into the repository:

```bash id="cdrepo01"
cd BindAI
```

---

## Create a Virtual Environment

### Windows

```powershell id="venvwin01"
python -m venv .venv

.venv\Scripts\activate
```

### Linux / macOS

```bash id="venvunix01"
python -m venv .venv

source .venv/bin/activate
```

After activation, your terminal should display the virtual environment name.

Example:

```text id="venvoutput01"
(.venv)
```

---

## Install in Editable Mode

Install BindAI directly from the repository.

```bash id="editable01"
pip install -e .
```

Editable mode allows source code changes to become immediately available without reinstalling the package.

---

# Updating BindAI

To upgrade to the latest published version:

```bash id="upgrade01"
pip install --upgrade bindai
```

If you're using the source repository, pull the latest changes and reinstall if necessary.

```bash id="gitpull01"
git pull

pip install -e .
```

---

# Common Issues

## `ModuleNotFoundError`

Ensure that your virtual environment is activated.

If you're developing from source, reinstall the project.

```bash id="fixmodule01"
pip install -e .
```

---

## Missing API Key

If the provider reports an authentication error, verify that your `.env` file contains the required credentials.

Example:

```text id="apikey01"
OPENAI_API_KEY=your_api_key_here
```

---

## Unsupported Python Version

Verify your Python installation.

```bash id="pythoncheck01"
python --version
```

BindAI requires **Python 3.11 or newer**.

---

## CLI Not Found

If the `bindai` command is unavailable after installation, ensure that the Python Scripts directory is included in your system PATH.

You can also invoke the CLI directly:

```bash id="modulecli01"
python -m bindai_cli --help
```

---

## Provider Configuration Issues

If your application cannot connect to a language model:

1. Verify your API key.
2. Confirm the selected provider in `bindai.toml`.
3. Run:

```bash id="doctor02"
bindai doctor
```

to identify any configuration problems.
