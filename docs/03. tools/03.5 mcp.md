# MCP

MCP (Model Context Protocol) is not a supported integration in the current BindAI V1 product.

BindAI V1 uses its native tool system to expose functionality to agents and workflows. This page documents that scope and does not provide MCP setup or usage instructions.

## Supported Tool Workflow

The native tool workflow is:

```text
Project Tool
    |
    v
BindAI Tool
    |
    v
Agent / Workflow
```

Tools follow BindAI's tool execution contract, including `ToolResult`.

A simple project tool can be defined using the `@tool` decorator:

```python
from bindai_tool import tool


@tool
def echo(text: str) -> str:
    return text
```

Use the project's supported tool discovery and workflow mechanisms to make project tools available to workflows.

## MCP Support Status

The current V1 product does not provide a supported MCP integration workflow. Do not treat MCP servers, MCP tool discovery, MCP sessions, MCP resources, MCP prompts, or MCP-specific credential management as available V1 capabilities.

For current tool usage, refer to:

* [Tool overview](03.1%20overview.md)
* [Creating tools](03.2%20creating-tools.md)
* [Tool context](03.3%20tool-context.md)
* [Tool results](03.4%20tool-results.md)

## Summary

Use BindAI's native tool system for the supported V1 agent and workflow tool functionality. MCP integration is not available as a supported V1 feature.
