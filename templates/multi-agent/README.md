# Multi-Agent Chat Template

A multi-agent chat system built with BindAI framework. This template allows you to interact with multiple specialized AI agents, each with different roles and expertise.

## Features

- 🤖 Multiple specialized agents (researcher, writer, summarizer, coder)
- 🔄 Switch between agents on the fly
- 📝 Each agent has customized instructions
- 🎯 Specialized responses based on agent role
- 💬 Interactive chat interface
- ⚙️ Easy configuration via YAML
