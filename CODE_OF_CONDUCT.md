# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in our
community a harassment-free experience for everyone, regardless of age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, religion, or sexual identity and
orientation.

We pledge to act and interact in ways that contribute to an open, welcoming,
diverse, inclusive, and healthy community.

---

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and welcoming.
- Accepting constructive feedback gracefully.
- Focusing on what is best for the community.
- Showing empathy toward others.
- Helping newcomers learn and grow.
- Using inclusive and professional language.

Examples of unacceptable behavior include:

- Harassment or discrimination of any kind.
- Personal attacks, insults, or trolling.
- Publishing private information without permission.
- Sexualized language or imagery.
- Threatening or abusive behavior.
- Any conduct that could reasonably be considered inappropriate in a professional environment.

---

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing our standards of
acceptable behavior and will take appropriate and fair corrective action in
response to any behavior they deem inappropriate, threatening, offensive, or
harmful.

Maintainers have the right and responsibility to remove, edit, or reject
comments, commits, code, issues, discussions, pull requests, and other
contributions that are not aligned with this Code of Conduct.

---

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- Project documentation
- Community chats
- Any official BindAI communication channels

It also applies when an individual is officially representing the project in
public spaces.

---

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please
contact the project maintainers privately.

You can report concerns by opening a confidential security report on GitHub or
by contacting the maintainers through the project's official communication
channels.

All reports will be reviewed promptly and handled respectfully.

---

## Enforcement Guidelines

Project maintainers may take actions including:

- Warning
- Temporary suspension
- Permanent ban from the community
- Removal of contributions that violate this Code of Conduct

Enforcement decisions will be based on protecting the community and maintaining a
welcoming environment.
